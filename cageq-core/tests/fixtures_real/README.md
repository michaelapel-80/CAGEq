Real headphone measurements and a target curve for `tests/fit_real_headphones.rs`, laid out
exactly like `cageq-catalog`'s on-disk cache (`files/<path with / folded to __>`) so the test runs
offline by pointing `CAGEQ_CACHE_DIR` here.

From [AutoEq](https://github.com/jaakkopasanen/AutoEq) by Jaakko Pasanen (MIT license):
the Sennheiser HD 800 S and AKG K812 measurements by oratory1990, and the Harman over-ear 2018
target. Unmodified copies of `measurements/oratory1990/data/over-ear/*.csv` and
`targets/Harman over-ear 2018.csv`.
